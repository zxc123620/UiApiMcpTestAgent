# 梁场2.0生产管理系统接口文档

##  预制梁参数管理

### 1. 接口概述

| 属性         | 说明                                                         |
| :----------- | :----------------------------------------------------------- |
| **接口名称** | 获取梁场预制梁参数列表                                       |
| **请求方式** | `GET`                                                        |
| **接口路径** | `/api/v1/beam-yard/parameters`（示例路径，实际以网关配置为准） |
| **接口描述** | 分页查询梁场预制梁的详细技术参数、位置里程、几何尺寸及附属设施配置。默认过滤逻辑删除数据，支持按项目/桥梁/墩台号等维度筛选。 |
| **数据格式** | `application/json`                                           |

### 2. 请求参数

#### 2.1 分页与查询参数

| 参数名          | 类型    | 必填 | 默认值 | 说明                             |
| :-------------- | :------ | :--: | :----: | :------------------------------- |
| `pageNum`       | Integer |  否  |  `1`   | 当前页码                         |
| `pageSize`      | Integer |  否  |  `10`  | 每页条数                         |
| `unitProjectId` | String  |  否  |   -    | 所属单位工程ID                   |
| `bridgeId`      | String  |  否  |   -    | 所属桥梁ID                       |
| `beamName`      | String  |  否  |   -    | 梁段名称/里程范围（模糊匹配）    |
| `startPierName` | String  |  否  |   -    | 起始墩/台名称                    |
| `isDeleted`     | String  |  否  |  `0`   | 逻辑删除标识（0:正常, 1:已删除） |

#### 3.2 `data.list` 字段说明

为提升可读性，字段已按业务模块分组：

| 字段名                 | 类型    | 说明                                         |
| :--------------------- | :------ | :------------------------------------------- |
| `paramId`              | String  | 参数记录主键ID                               |
| `unitProjectId`        | String  | 所属单位工程ID                               |
| `bridgeId`             | String  | 所属桥梁ID                                   |
| `beamName`             | String  | 梁段名称/里程范围                            |
| `name`                 | String  | 梁体类型名称（如：`箱梁32M有声单线直线`）    |
| `designDrawingsNumber` | String  | 设计图纸编号                                 |
| `zpType`               | String  | 支座类型编码                                 |
| `beamBodyType`         | String  | 梁体结构类型（`1`:T梁, `2`:箱梁等）          |
| `steelNum`             | Integer | 钢筋用量/数量                                |
| `platformBeamId`       | String  | 平台梁体ID                                   |
| `beamPosition`         | String  | 梁体位置（`1`:中梁, `2`:边梁, `3`:次边梁等） |

| 字段名                                        | 类型   | 说明                                         |
| :-------------------------------------------- | :----- | :------------------------------------------- |
| `startPierId` / `endPierId`                   | String | 起始/结束墩台ID                              |
| `startPierName` / `endPierName`               | String | 起始/结束墩台名称                            |
| `startCenterKilo` / `endCenterKilo`           | String | 起始/结束中心里程（展示格式：`DK8+863.507`） |
| `startCenterKiloNum` / `endCenterKiloNum`     | Double | 起始/结束里程数值（单位：**米**）            |
| `startCenterKiloTitle` / `endCenterKiloTitle` | String | 里程前缀（如：`DK`）                         |
| `pierBetween`                                 | Double | 墩台间距（单位：米）                         |

| 字段名                   | 类型   | 说明                       |
| :----------------------- | :----- | :------------------------- |
| `preBeamGap`             | Double | 前梁缝/间隙（米）          |
| `backBeamGap`            | Double | 后梁缝/间隙（米）          |
| `startRailSurfaceHeight` | Double | 起始轨面高度（米）         |
| `endRailSurfaceHeight`   | Double | 结束轨面高度（米）         |
| `startPierStoneHeight`   | Double | 起始墩石高度（米，可为空） |
| `endPierStoneHeight`     | Double | 结束墩石高度（米，可为空） |
| `crossSlope`             | Double | 横向坡度（可为空）         |
| `slope`                  | Double | 纵坡坡度                   |
| `beamLength`             | Double | 梁体实际长度（米）         |
| `beamSpan`               | Double | 梁体设计跨径（米）         |

| 字段名             | 类型   | 说明                           |
| :----------------- | :----- | :----------------------------- |
| `haveLeftBarrier`  | String | 左侧护栏（`0`:无, `1`:有）     |
| `haveRightBarrier` | String | 右侧护栏（`0`:无, `1`:有）     |
| `touchLines`       | String | 接触网线索数量/类型            |
| `ag`               | String | 接触网参数指标（如：`0.0322`） |

| 字段名                    | 类型   | 说明                                     |
| :------------------------ | :----- | :--------------------------------------- |
| `supportTypeOne` ~ `Five` | String | 1#~5#支座类型编码                        |
| `supportModel`            | String | 支座型号                                 |
| `supportLocation`         | String | 支座位置参数说明（分号分隔的拼接字符串） |

| 字段名                      | 类型   | 说明                                         |
| :-------------------------- | :----- | :------------------------------------------- |
| `direction`                 | String | 施工/架设方向（`1`:正向, `2`:反向等）        |
| `remarks`                   | String | 备注说明                                     |
| `tenantId`                  | String | 租户ID                                       |
| `createBy` / `updateBy`     | String | 创建/更新人ID                                |
| `createTime` / `updateTime` | String | 创建/更新时间（格式：`yyyy-MM-dd HH:mm:ss`） |
| `isDeleted`                 | String | 逻辑删除标识（`0`:未删除, `1`:已删除）       |
| `unitProjectName`           | String | 所属单位工程名称（冗余展示字段）             |
| `bridgeName`                | String | 所属桥梁名称（冗余展示字段）                 |
| `bridgeType`                | String | 桥梁类型编码                                 |

### 5. 业务说明与注意事项

1. **分页标准**：响应结构完全兼容 `PageHelper` / `MyBatis-Plus` 默认分页对象，前端可直接绑定分页组件。
2. **空值兼容**：`startPierStoneHeight`、`ag`、`remarks`、`beamPosition` 等字段在数据未录入时可能返回 `null` 或 `""`，前端展示需做空值兜底处理。
3. **里程格式化**：数值字段 `startCenterKiloNum` 等以**米**为单位，建议前端结合 `startCenterKiloTitle` 动态拼接为 `DK+xxx.xxx` 格式展示。
4. **逻辑删除**：默认仅返回 `isDeleted = '0'` 的有效数据。若需查看已删除记录，需显式传入 `isDeleted=1`（仅限管理员角色）。
5. **权限隔离**：接口底层已按 `tenantId` 及当前用户授权的项目/桥梁范围进行过滤，返回数据均属于当前租户及权限域内。
6. **冗余字段**：`unitProjectName`、`bridgeName` 为关联查询冗余字段，仅用于列表页快速展示，详情编辑时请以 ID 为准。

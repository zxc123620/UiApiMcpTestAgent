# 接口文档

## 登陆接口

### 接口信息

| 项目 | 内容 |
| --- | --- |
| 接口名称 | 登陆接口 |
| 接口路径 | `/api/pub/login/loginIn.do` |
| 请求方式 | `POST` |
| 请求类型 | `application/json` |
| 响应格式 | `application/json` |

### 请求体

请求体为 JSON 格式，字段名称为 `data`，其值为 **RSA 加密后的数据**,需要使用工具`login_data_encrypt` 进行加密。

RSA 加密前的明文内容包含以下字段：

| 字段名称 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| userAccount | string | 是 | 用户名 |
| userPassword | string | 是 | 密码 |

#### 请求体结构

```json
{
  "data": "RSA加密后的数据"
}
```

#### 返回字段说明

**顶层字段**

| `timestamp` | `1791880753453` | 响应生成时间戳（毫秒） |

## 添加组织机构接口

### 接口说明

用于在系统中添加组织机构（集团公司 / 建设单位 / 建设项目 / 标段 / 梁场），层级关系：

- **运维单位**（deptType = 1）系统自带，不需要添加
- **集团公司**（deptType = 2）挂载运维单位下
- **建设单位**（deptType = 3）挂在集团公司下
- **建设项目**（deptType = 4）挂在建设单位下
- **标段**（deptType = 5）挂在建设项目下
- **梁场**（deptType = 6）挂在标段下
---

### 基本信息

| 项目 | 内容 |
| --- | --- |
| 接口名称 | 添加组织机构 |
| 接口路径 | `/api/pub/dept/addDeptInfo.ajax` |
| 请求方式 | POST |
| 请求体格式 | `application/json` |
| 响应格式 | `application/json` |
| 认证方式 | 请求 Header 中携带 `Authorization` 参数 |

---

### 请求头参数

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| Authorization| string | 是 | 身份认证令牌，用于接口鉴权,值为登陆接口中的userToken |

### 请求体参数（JSON）

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| deptName | string | 是 | 组织机构名称,有重复校验 |
| deptCode | string | 是 | 组织机构编码,有重复校验 |
| parentDept | string | 是 | 父级组织机构 ID。从获取组织机构接口中得到 |
| deptType | string | 是 | 组织机构类型：`2`-集团公司，`3`-建设单位，`4`-建设项目，`5`-标段，`6`-梁场 |
| deptOrder | int | 否 | 排序序号，同层级下数值越小越靠前,返回数据的顺序需要根据该项进行排序 |
| deptRemark | string | 否 | 备注信息 |

#### 请求示例

```http
POST /api/pub/dept/addDeptInfo.ajax
Content-Type: application/json
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

{
  "deptName": "测试机构1",
  "parentDept": "xxxxxxxxx",
  "deptCode": "112233",
  "deptType": "2",
  "deptOrder": 1,
  "deptRemark": "dsfasdfasdfa"
}
```
### 返回参数

| 字段 | 示例值 | 描述 |
|---|---|---|
| `status` | `"1"` | 业务状态码。`1` 表示成功，`0` 表示失败 |
| `code` | `"200"` | HTTP/业务响应码。会一直返回`200`  |
| `message` | `null` | 提示信息。成功时通常为 `null` |
| `timestamp` | `1791880753453` | 响应生成时间戳（毫秒） |
| `data` | `{...}` | post请求没有数据 |
---

### 注意事项

1. 必须在 Header 中携带有效的 `Authorization`，否则接口将返回鉴权失败。
2. `parentDept` 需与 `deptType` 的层级关系匹配，否则可能返回业务错误。
3. `deptOrder` 用于同级排序，建议传整数。

---

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `deptId` | `string` | 是 | 组织机构（部门）ID，值需从「获取组织机构接口」的返回结果中获取 |

### 返回参数

| 字段 | 示例值 | 描述 |
|---|---|---|
| `status` | `"1"` | 业务状态码。`1` 表示成功，`0` 表示失败 |
| `code` | `"200"` | HTTP/业务响应码。会一直返回`200`  |
| `message` | `null` | 提示信息。成功时通常为 `null` |
| `timestamp` | `1791880753453` | 响应生成时间戳（毫秒） |
| `data` | `{...}` | 成功后没有数据 |
---

###  请求示例

```http
GET /api/base/bfmBaseDeptRelation/deleteBfmBaseDeptRelationByDeptId.ajax?deptId=xxxx
```

## 获取组织机构接口

### 基本信息

| 项目 | 内容 |
|---|---|
| 接口名称 | 获取组织机构（部门）树形列表 |
| 请求路径 | `/api/pub/dept/queryAllDeptTreeList.ajax` |
| 请求方式 | `GET` |
| 鉴权方式 | 需要携带 `Authorization` 请求头 |
| 功能描述 | 查询全部组织机构，并以树形结构返回，用于获取有效的 `deptId` |

### 请求头参数

| 请求头 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `Authorization` | `string` | 是 | 登录后获取的访问令牌，格式为 `Bearer {token}` |

### 请求参数

无（如接口默认返回全部节点，则无需额外传参）。


### 返回参数

| 字段 | 类型 | 说明 |
|---|---|---|
| `status` | `string` | 业务状态码。`1` 表示查询成功受理，`0` 表示查询被拒绝 |
| `code` | `string` | 响应码。`200` 表示请求处理成功 |
| `timestamp` | `number` | 响应生成时间戳（毫秒） |
| `data` | `array` | 组织机构树形列表，数组元素为部门节点对象 |

**data字段**

| 字段 | 类型 | 说明 |
|---|---|---|
| `deptId` | `string` | 部门唯一标识，可作为删除组织机构接口的入参 |
| `deptName` | `string` | 部门名称 |
| `deptNo` | `string` | 部门编号 |
| `parentId` | `string` | 父级部门 ID，根节点通常为 `"0"` |
| `deptCode` | `string` | 部门编码 |
| `deptType` | `string` | 部门类型 |
| `deptOrder` | `number` | 同级排序号 |
| `deptRemark` | `string` | 部门备注 |
| `children` | `array` | 子部门列表，结构与本节点相同，叶子节点通常为空数组 |


### 请求示例

```http
GET /api/pub/dept/queryAllDeptTreeList.ajax
Authorization: Bearer {token}
```
